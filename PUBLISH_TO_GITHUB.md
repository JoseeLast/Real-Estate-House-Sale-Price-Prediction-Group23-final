# Publish and deploy the Module 6 project

For the complete browser-based procedure, read [`GITHUB_AND_STREAMLIT_DEPLOYMENT_GUIDE.md`](GITHUB_AND_STREAMLIT_DEPLOYMENT_GUIDE.md). It explains how to create the GitHub repository, upload the extracted project files on GitHub.com, commit the changes, deploy `app.py` from Streamlit Community Cloud, test the deployed page, and record verified links.

The project is prepared for publication, but a public repository URL and live Streamlit URL must be created and verified by the group. Do not represent either as live before completing the steps.
